OpenAudio's first repository prerelease: application audio controls, local browser-tab companion, and a customizable vinyl listening room with automatic artwork.

Requires macOS 15+ and Apple silicon. Bundled companion: 0.5.0.

Download the ZIP, extract OpenAudio.app and move it to Applications. **This development build is ad-hoc signed, not Developer ID signed or notarized; macOS may block it.** Building from source is also supported. Safari works as a combined app; independent Safari tabs are not implemented.

Artwork now fetches automatically for the selected visible song, retries temporary service failures, and uses public-page fallback for suggestions. Source artwork and cached covers take priority. Third-party availability is not guaranteed.

The workflow runs native/model/artwork and browser fixture checks before packaging. No live audio, provider, browser or permission tests run in CI. See CHANGELOG.md and the verification documents for scope. SHA256SUMS verifies downloaded file integrity.
